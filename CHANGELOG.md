# Changelog

Changes to Win Stats are recorded here.

## [0.2.1] - 2026-11-04

- The taskbar keeps the module order chosen in Settings.

## [0.2.0] - 2026-11-03

- Optional CPU temperature through a background sensor service and the official PawnIO driver.
- Session-high CPU and GPU temperatures, with a reset.

## [0.1.0] - 2026-10-20

- Initial release with CPU, RAM, GPU, disk, network, and available GPU sensor readings.
- Configurable taskbar display and Pulse notification-area tray controls.
- Self-contained Windows 11 x64 installer and portable ZIP.
- MIT license for the original project and landing page.
