# Product media

These PNGs are rendered by Win Stats' actual WPF and taskbar UI, using deterministic illustrative values. They are not desktop screenshots or performance measurements. No personal process names or network addresses are captured.

Regenerate on Windows: `WinStats.exe --media-export <output-directory>`.

`win-stats-demo.mp4` is a silent, web-ready copy of a desktop walkthrough. Its drive label and local network address are obscured before publication. The video is loaded only when a visitor presses play; `win-stats-demo-poster.jpg` is its preview image.
