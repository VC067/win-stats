Questions

A few things to know before you try it.

How do I install and open it?

Download WinStats-Setup-x64.exe. The installer adds Win Stats to your Start menu. Prefer portable? Extract the entire portable ZIP and run WinStats.exe from that folder. No separate .NET installation is needed.

Where is the app window?

Win Stats lives on your taskbar and in the notification area. Click a reading to see its card. Click the blue Pulse tray icon to open Settings, or right-click it for the menu. Windows may place the icon in the hidden icons area.

Which Windows versions?

Windows 11, 64-bit. Windows 10 and ARM are not verified.

Why do some values say "--"?

Windows or the GPU driver did not provide that reading. CPU temperature stays blank because there is no sensor driver.

Does it contact an external service?

A user-initiated update check requests public release information from GitHub. Public IP lookup is off by default. If you enable it in Settings, Win Stats contacts api.ipify.org to find the internet-facing IP address of your connection and display it in the network card.

How do updates work?

Select Check for updates in Settings to request the latest public release tag from GitHub. The check sends no system readings or identifying system details. If a newer version is available, Win Stats offers to open GitHub Releases. Updates are installed manually. Quit Win Stats from its tray menu before running the new installer or replacing the extracted portable files. Your settings are kept.
